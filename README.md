# Люми · уведомления (Android)

Крошечное приложение: показывает напоминания от Люми с твоим роботом в строке состояния.
Расписание присылает плагин Obsidian (шаг 2), а будильники ставит сам телефон — работает при закрытом Obsidian.

## Как получить APK без компьютерной сборки
1. Создай бесплатный аккаунт на github.com и новый репозиторий (можно приватный).
2. Загрузи в него ВСЁ содержимое этой папки (кнопка «Add file → Upload files»), включая скрытую папку `.github`.
   Удобнее с компьютера или в мобильном браузере в режиме «Версия для ПК».
3. Вкладка **Actions → build-apk → Run workflow**. Через ~3–5 минут внизу страницы запуска появится файл `lumi-notify-apk`.
4. Скачай, распакуй, установи `app-debug.apk` (разреши установку из этого источника).
5. Открой «Люми», разреши уведомления, нажми «Тест через 5 секунд».

## Если телефон Xiaomi/Huawei/Samsung
В «Настройки приложения» включи «Автозапуск» и убери ограничения батареи, иначе система может гасить напоминания.

## Анимация
В шторке шарик водит глазами и моргает (покадровая смена картинок). Если на твоей оболочке уведомление выглядит криво — в приложении кнопка «Анимация в шторке» переключает на обычный вид.
Цвет шарика меняется в `tools/make_icons.py` (строки TOP/BOTTOM), потом `python3 tools/make_icons.py`.

## Обновление: расписание
Плагин присылает расписание ссылкой lumi://schedule — её принимает прозрачный экран ScheduleActivity (без мигания приложения). Плагин делает это раз в 1–2 дня.

## Новое
- Тихие часы, лимит напоминаний в день, пауза — в приложении (раздел «Тихие часы и частота»).
- Виджет на главный экран: кнопка «Добавить виджет на экран» или долгое нажатие на экране → Виджеты → Люми.
- ИИ в чате Obsidian ставит напоминания и меняет эти настройки сам (инструменты phone_*).
